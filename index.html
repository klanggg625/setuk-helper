범교과 세특 초안 도우미

설정 입력 → 학생별 관찰 내용 입력 → 프롬프트 복사 후 ChatGPT에 붙여넣기 → 검토한 확정본 보관. 스프레드시트 흐름을 한 화면으로 옮겼습니다.

1. 설정

교과명을 입력하면 주요 학습 요소·핵심역량 예시가 채워집니다. 직접 고쳐도 됩니다.

완성된 프롬프트 미리보기

  






  
2. 학생별 작업

  
관찰 내용은 키워드나 짧은 메모도 괜찮습니다. 번호 칸에는 실명·학번 대신 가상 표기(예: 학생1)만 쓰세요.

  
    
    
  1. 관찰 내용을 입력하고 프롬프트+관찰 복사를 누릅니다.
    2. 
    
  2. ChatGPT 새 채팅에 붙여넣고, 나온 문장을 생성 결과에 붙여넣습니다.
    3. 
    
  3. 교사가 검토·수정한 뒤 확정본에 보관합니다.
    4. 
  

  

  

    
    
    
  

  
전체 복사는 번호와 확정본을 탭으로 구분해 한 줄씩 복사하므로, 스프레드시트에 그대로 붙여넣을 수 있습니다.






  
교과별 핵심역량 예시

  
필요한 교과의 복사를 누르면 그 내용만 복사됩니다. 설정에 적용은 맨 위 설정 칸을 그 교과로 바꿉니다.

  






  

    개인정보와 최종 책임
    
    
      
  • 입력한 내용은 이 브라우저에만 저장됩니다. 공용 컴퓨터에서는 쓴 뒤 입력 내용 전체 삭제를 눌러 주세요.
    • 
      
  • AI 서비스에는 실명·학번 등 개인을 알아볼 수 있는 정보를 넣지 않습니다. 소속 교육청의 생성형 AI 활용 지침도 확인하세요.
    • 
      
  • 생성된 문장은 초안입니다. 교사가 관찰한 사실과 대조해 검토·수정한 뒤 확정본을 입력하세요.
    • 
      
  • 바이트 수는 한글 3바이트, 줄바꿈 2바이트로 센 추정치입니다. 약 1,200바이트는 목표 분량이며, 실제 한도와 기재 요령은 입력 화면과 해당 학년도 기재요령 원문으로 확인하세요.
